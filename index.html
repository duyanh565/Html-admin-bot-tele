Sao lưu & chuyển server

Tải toàn bộ dữ liệu shop xuống hoặc nhập dữ liệu vào database hiện tại.

Tải bản sao lưu

Bao gồm người dùng, số dư, vai trò seller, giá riêng, giá mặc định người dùng/seller, trạng thái ban, kho/key đã bán, giao dịch, cấu hình, cây danh mục, sản phẩm tự tạo, tên đã chỉnh sửa và trạng thái ẩn/hiện và dấu sản phẩm xóa vĩnh viễn.

Khôi phục từ tệp

Nhập/gộp các bản ghi trong JSON vào database hiện tại. Bản ghi trùng sẽ được cập nhật; dữ liệu không có trong file sẽ không bị xóa.

Tệp backup chứa key bán hàng và thông tin cấu hình. Chỉ tải lên tệp do bạn tin cậy và giữ file ở nơi an toàn.

Quy trình chuyển server

  1. Tải backup từ server đang chạy.
  2. Trên server mới, cấu hình cùng bot token và database mới, đặt mật khẩu ADMIN_PASSWORD.
  3. Khởi chạy bot và mở trang admin mới, đăng nhập.
  4. Vào đây chọn file JSON rồi nhập dữ liệu.
  5. Kiểm tra danh sách người dùng, sản phẩm, số dư và kho trước khi chuyển hẳn lưu lượng.
